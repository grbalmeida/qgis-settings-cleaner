about=This plugin resets QGIS by deleting the active user profile: every setting (language, proxy, CRS, connections, WMS/WFS and XYZ services) and everything else kept in the profile (saved passwords, installed plugins, user styles, bookmarks, Processing models and scripts). QGIS then closes and starts with a fresh profile next time. Useful for troubleshooting, training rooms and shared workstations. Project and data files are not touched.
about[pt]=Este plugin restaura o QGIS excluindo o perfil de usuário ativo: todas as configurações (idioma, proxy, SRC, conexões, serviços WMS/WFS e XYZ) e tudo o mais guardado no perfil (senhas salvas, plugins instalados, estilos do usuário, marcadores espaciais, modelos e scripts do Processamento). O QGIS é fechado e abre com um perfil novo na próxima vez. Útil para resolver problemas, salas de treinamento e estações compartilhadas. Projetos e arquivos de dados não são alterados.
